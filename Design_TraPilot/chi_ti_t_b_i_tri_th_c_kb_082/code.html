Đồng bộ JDK trên GitHub Actions (Khắc phục javac release flags version mismatch)

Java 21 GitHub Actions v4 Maven Compiler Plugin Temurin Distribution
MĐ Minh Đạt • Duyệt bởi Bảo Trâm
| 14/05/2024 · 09:30 GMT+7
verified Kiểm chứng: Run #483 thành công
01

Tóm tắt bối cảnh & Triệu chứng

Khi các repository microservice tiến hành nâng cấp phiên bản bytecode target trong tệp pom.xml lên Java 21 bằng thuộc tính cấu hình <maven.compiler.release>21</maven.compiler.release>, nhưng runner CI của GitHub Actions (ubuntu-latest) vẫn được giữ ở cấu hình khởi tạo mặc định thấp hơn (thông thường là Temurin JDK 17).

bug_report Dấu hiệu lỗi điển hình trong Runner Log (Console Stderr)
[ERROR] Fatal error compiling: error: release version 21 not supported
[ERROR] -> [Help 1] http://cwiki.apache.org/confluence/display/MAVEN/MojoExecutionException
[ERROR] Failed to execute goal org.apache.maven.plugins:maven-compiler-plugin:3.11.0:compile

03

Cách khắc phục đã kiểm chứng (Verified Resolution)

Cần thực hiện đồng bộ song song ở 2 vị trí: Workflow CI của GitHub Actions và thuộc tính maven trong kho mã nguồn.

1

Cập nhật GitHub Actions Workflow Step

Nâng cấp action actions/setup-java từ phiên bản cũ v3 lên v4 và khai báo tường minh phiên bản java-version: '21' với nhà phân phối temurin:

description .github/workflows/ci.yml 
# Cấu hình môi trường Java 21 tương thích release flag 21
- name: Set up JDK 21
  uses: actions/setup-java@v4
  with:
    distribution: 'temurin'
    java-version: '21'
    cache: 'maven'
2

Đồng bộ cấu hình pom.xml (Maven Compiler Plugin)

Đảm bảo các thuộc tính compiler chỉ định đúng release bytecode đồng bộ:

code pom.xml 
<properties>
  <maven.compiler.release>21</maven.compiler.release>
  <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
</properties>
04

Phương án dự phòng (Toolchains cho môi trường Hybrid)

Trong trường hợp runner bắt buộc phải thực thi bằng Java 17 do ràng buộc agent bảo mật hoặc plugin Sonar cũ, hãy triển khai tệp ~/.m2/toolchains.xml để Maven phân tách runtime chạy plugin và JDK trình biên dịch:

info Lưu ý khi dùng Maven Toolchains
Cần bổ sung thêm một bước cài đặt JDK 21 song song qua actions/setup-java thứ hai không thiết lập làm default path, sau đó chỉ định maven-toolchains-plugin trỏ tới JAVA_HOME của bản cài 21.
