Đồng bộ JDK trên GitHub Actions (Khắc phục javac release flags version mismatch) arrow_outward

Khi nâng cấp target bytecode lên Java 21, bắt buộc cập nhật actions/setup-java sang java-version: '21' hoặc cấu hình maven-toolchains-plugin để tránh lỗi compile invalid target release: 21.

code .github/workflows/pipeline.yml (Patch mẫu khuyến nghị) 
- name: Cài đặt JDK 21 Temurin
  uses: actions/setup-java@v4
  with:
    distribution: 'temurin'
    java-version: '21'
    cache: 'maven'
