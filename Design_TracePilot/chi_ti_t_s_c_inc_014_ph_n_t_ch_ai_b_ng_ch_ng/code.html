1. Tóm tắt phân tích

TracePilot Triage Core

Hệ thống phát hiện mâu thuẫn trực tiếp giữa phiên bản JDK được cài đặt trên GitHub Actions runner (Temurin 17.0.10) và cờ cấu hình javac release 21 được chỉ định trong file cấu hình pom.xml của kho lưu trữ orders-api. Trình biên dịch javac từ chối cờ này vì phiên bản compiler nội tại chỉ hỗ trợ tối đa Java 17.

Loại lỗi chẩn đoán sync_problem Bytecode version mismatch
Vị trí kích hoạt terminal Job: build-backend
Mức độ ảnh hưởng block Chặn toàn bộ luồng CI
troubleshoot

2. Nguyên nhân nghi ngờ (Root Cause Breakdown)

2 bằng chứng xác thực

Workflow CI ci.yml hiện đang sử dụng action actions/setup-java@v3 với cấu hình java-version: '17'.

Tuy nhiên, trong commit 9f3a2bd mới nhất, cấu hình Maven pom.xml đã được cập nhật cờ biên dịch:

<maven.compiler.release>21</maven.compiler.release>

Sự chênh lệch này khiến javac v17 dừng tiến trình ngay khi nhận yêu cầu đóng gói target Java 21 [1] build-backend-stdout.log:51 north_east . Tình huống tương tự từng được chuẩn hoá trong tài liệu kỹ thuật của tổ chức [2] KB-082 Đồng bộ JDK open_in_new .

healing

3. Cách khắc phục đề xuất (Proposed Resolution)

Tự động hoá sẵn sàng
1
Cập nhật workflow GitHub Actions Chỉnh sửa file .github/workflows/ci.yml để chỉ định runner nạp bộ công cụ Temurin JDK 21.
2
Kiểm tra tương thích ngược và chạy lại CI Đẩy commit mới lên nhánh và xác nhận bước mvn test thông qua hoàn toàn.
